# VR ショップウォークスルー

3Dモデル（お店の内装など）をブラウザに読み込んで、PCやMeta Quest 3のVRで歩き回れるWebアプリです。
気になった場所に付箋のような「メモ」を貼り付けて、セーブ・ロードもできます。

**公開ページ：** https://yoshioyoshidaapa-stack.github.io/my-website/

---

## できること

- 3Dモデルの読み込み（**GLB / GLTF / OBJ / STL / FBX**）
- PCでのウォークスルー（キーボード＋マウス）
- Meta Quest 3 などでのVRウォークスルー（WebXR）
- 空間へのメモ配置（キーボード入力・音声入力・VRキーボード）
- VRキーボードでのひらがな／カタカナ／英字入力と漢字変換
- モデルの拡大・縮小
- セーブ／ロード（モデルとメモを1つのJSONファイルに保存）

## 使い方

1. 公開ページを開く
2. 「ファイルを選択」から3Dモデルを選ぶ
3. 歩き回る（操作は下の表）
4. VRで見るときは、Quest 3 のブラウザで公開ページを開き「VRモード開始」を押す

> **おすすめ形式は GLB です。** .gltf 形式でテクスチャなどが別ファイルになっているものは読み込めません。
> Blender などから書き出すときは「glTF Binary (.glb)」を選んでください。

## 操作方法

### PC

| 操作 | 内容 |
|---|---|
| W / A / S / D（または矢印キー） | 前後左右に移動 |
| マウスドラッグ | 視点を回す |
| マウスホイール / Q / E | ズームイン・ズームアウト |
| M | メモモードのオン・オフ |
| メモモード中にクリック | その場所にメモを置く |

### VR（Meta Quest 3）

| 操作 | 内容 |
|---|---|
| 左スティック | 前後左右に移動 |
| 右スティック（左右） | 向きを変える |
| 右トリガー | メモを置く／キーボードのキーを押す |
| 左トリガー | 上に移動（キーボード表示中はキーを押す） |
| 左グリップ | 下に移動（床の高さで少し引っかかる） |

## セーブとロード

- 「セーブ」を押すと `vr-scene-（数字）.json` がダウンロードされます。モデル本体・位置・大きさ・メモがすべて入っています。
- 「ロード」でそのファイルを選ぶと元の状態に戻ります。
- モデルの中身もファイルに入るので、セーブファイルは元のモデルファイルの約1.3倍の大きさになります。

## 注意点

### 漢字変換について（情報の扱い）

VRキーボードの漢字変換は、入力したひらがなを **無料の中継サービス（corsproxy.io / allorigins.win）経由で Google の変換サービスに送って** 変換候補を受け取っています。

- 中継サービスの運営者は、送られた文字を見ることができます
- 無料サービスのため、予告なく止まることがあります（その場合は変換されず、ひらがなのまま入力されます）

**社外秘の内容を入力する場合は、漢字変換をオフにしてください。**
`js/VRKeyboard.js` の次の行を `false` に変えると、外部への送信が止まります。

```js
this.ENABLE_ONLINE_KANJI = true;   // ← false にするとオフ
```

### 音声入力について

音声入力はブラウザの音声認識機能を使います（Chrome では音声が Google のサーバーで処理されます）。対応していないブラウザでは「非対応」と表示されます。

## ファイル構成

```
index.html             画面の見た目とボタン
js/
├── main.js            全体のまとめ役（起動・操作の振り分け）
├── SceneManager.js    3D空間・カメラ・照明・床
├── ModelLoader.js     3Dモデルの読み込み
├── PlayerControls.js  PCでの移動・視点操作
├── VRManager.js       VRコントローラーの操作
├── VRKeyboard.js      VR内のキーボード・漢字変換
├── MemoManager.js     メモの作成・削除
├── UIManager.js       ボタンやダイアログの管理
├── SaveManager.js     セーブ・ロード
└── utils.js           共通の部品（メモリ解放など）
```

使っているライブラリ：[three.js](https://threejs.org/) r128（インターネット経由で自動読み込み）

## 手元のパソコンで動かす場合

`index.html` をダブルクリックで開いても動きません（ブラウザの安全機能のため）。簡易サーバーを使って開いてください。

**VS Code を使う場合：**
1. 拡張機能「Live Server」をインストール
2. `index.html` を右クリック
3. 「Open with Live Server」を選ぶ

VRで試す場合は、Quest 3 から見られる HTTPS のアドレスが必要です。GitHub Pages（上の公開ページ）を使うのが一番簡単です。
